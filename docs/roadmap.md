# moxsh 产品路线图

> 最后更新：2026-11-14。下面是我们对外分享的产品方向。
> 规划类条目均为 **「待定」—— 可能做，也可能不做**，最终以实际发布的版本为准，不在此处做承诺。

## 已发布

| 版本 | 内容 |
| --- | --- |
| M1 | 工程骨架 + CI + 文档 |
| M2 | Rust 终端内核（PTY / VT 解析 / 回滚）+ 会话引擎 |
| M3 | 液态玻璃 UI 主体 + 真实终端渲染 |
| M4 | PRoot 容器引擎 + 图形化管理 + 插件商店 + AI Agent |
| M5 | Bootstrap 安装流程（国内 CDN 优先 + sha256 校验） |
| M6 | 首个可安装 APK（GitHub Release 出包，已发布） |

## 当前里程碑：M7（规划中）

M6 锁定首个可安装 APK 后，M7 聚焦**性能与生态深化**——把此前「规划中 · 待定」的方向收敛为明确目标，并把 `moxsh-terminal` 对齐到 MoX 全家桶 1.0.0 大版本：

| 版本 | 内容 |
| --- | --- |
| M7 | 性能与生态深化：120Hz 渲染 + glyph atlas 离屏缓存、端侧小模型接口、插件支付闭环（`.mox` 签名 + 权限 + 售卖）；`moxsh-terminal` 对齐全家桶 1.0.0 |

## 近期生态进展（2026-11-14 复核）

以下为近期**已发生 / 正在进行**的事实记录；规划类条目仍标注「待定」，不在此处做承诺。

- **MoX 全家桶 npm 包发布**：`@codecloud-dev/agent-core`（TS 通用内核 / SDK）与 `@codecloud-dev/moxwebgpu`（WebGPU / 渲染）已发布到 `@codecloud-dev` 组织；对应仓库在 README「大版本进度」表中的状态已同步更新为「已发布」。
- **官网 mox-site 安全加固**：全站响应统一补齐安全响应头；Functions 路由此前漏头的路径已修复并上线。
- **依赖体检与文档合规推进中**：MoX 全家桶各仓库正在开展依赖体检（含破坏性依赖变更守门）与文档合规核查，进行中，未承诺完成时间。

> 以上为事实记录，未发布的功能不在此处承诺。M7 及更远期方向仍按「规划中 / 待定」处理。

## 规划中（更远期，待定）

- **性能打磨（余下项）**：脏区 diff 精细化、NEON 汇编热路径优化（scroll diff / syscall）。
- **AI 能力深化**：接入更多模型，把"自然语言完成操作"做得更稳。
- **更多可能性**：跨设备能力、增值服务等——均待定，不承诺时间表。

## 关于 MoX 系列

moxsh 之外，我们也在探索 **moxbox**（文件管理与系统套件）、**moxcode**（移动端轻量 IDE）等方向，但都是**早期设想、待定**，是否落地、何时落地均未定。
